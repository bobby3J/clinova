Clinova — Product & Systems Blueprint

A focus-and-study companion for nursing and midwifery students — study library, AI practice, timed focus sessions, and flashcards on the student side; content, question-bank, and user administration on the other. This document is the design pass before we open an IDE: identity, actors, flows, architecture, and schema, sequenced so the Laravel + MySQL + React build has something solid to scaffold against.

StudentPrimary user. Studies, practices, tracks streaks. Scoped to their own track (Nursing / Midwifery) and data.
AdminOperates content, users, and the question bank. Same web app, role-gated routes and API middleware.
External — LLM APICalled server-side only, to generate/refresh AI Practice questions. Never touched directly by the client.

Identity

The mark reads as a single stroke: a heartbeat breaks the arc on one end, an amber cursor-dot caps the other — clinical vitals and an active study session, drawn as one open "C". Open on the right so it also doubles as a page corner or a "play" cue at small sizes.

Pulse → care

The open arc is a single continuous stroke, not a closed ring — it's meant to feel drawn mid-motion, like a session in progress rather than a static badge.

Amber dot → focus

A second, warm accent (never the same teal) marks "active" — reused across the app for running timers, unread badges, and the one warm chip in the palette below.

Scales down clean

Two shapes and one dot survive a 16px favicon; no gradients or fine detail to lose. Same mark works as the admin sidebar glyph at 18px.

Sheet 04

System Architecture

One React SPA serves both surfaces — student app and admin console are the same bundle, split by role-gated routes, sharing one Laravel API and one Sanctum session. AI generation and notifications are pushed to a queue so nothing in the request path waits on an external API.

Sheet 07

Technical Stack & Next Steps

Nothing exotic — the goal is a stack you can hold in your head six months from now, not the largest possible toolbox.

Frontend

React SPA

React 18 + TypeScript on Vite. TanStack Query owns server state (content, decks, sessions); a small Zustand store holds purely client state — the running timer. Tailwind for styling, React Router with a role guard splitting / from /admin/*.

reacttypescripttanstack-queryzustandtailwindcss
Backend

Laravel API

Laravel 11, Sanctum for SPA cookie auth against one users table with a role enum. Form Requests validate, Policies gate every admin endpoint. Laravel Queue (database driver to start) runs AI generation and notification jobs; the scheduler resets weekly goals and computes streaks nightly.

laravel 11sanctumpoliciesqueuescheduler
Data & storage

MySQL 8 + object storage

MySQL is the single source of truth (Sheet 05). Notes/audio/video go to local disk in dev and an S3-compatible bucket in production, referenced by URL from study_materials — never stored as blobs in the DB.

mysql 8eloquents3
AI Practice

Server-side only

The client never talks to the LLM directly. A dedicated AiPracticeService is the only caller, invoked from a queued job, with generated sets cached per topic so a quiz start is a cache read, not an API call.

queued jobper-topic cacheno client key exposure

Where we start coding

  1. Turn the ERD into migrationsusers, subjects, topics, study_materials, flashcard_decks, flashcards, sounds, study_sessions — the tables everything else hangs off.
  2. Auth + role scaffoldingSanctum SPA auth, the role enum, and the Policy classes that make /admin/* mean something on the API side, not just the frontend route.
  3. Ship Study With Me firstIt's the flagship screen in the reference design — build the timer + sound picker end to end before the rest of the library, so there's a working vertical slice early.
  4. Admin console incrementallyOverview + Content Library CRUD first (it unblocks everything else needing real data), Users and Analytics after.
  5. AI Practice lastIt's the one component with an external dependency and a cost model — build it once the cached-content pattern from Study Library already exists to copy.
